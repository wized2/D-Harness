# Skills

Use progressive disclosure:

1. `skill.list` — short names + descriptions  
2. `skill.read` with `name` — full instructions for that domain  

Load the domain skill **once** before the first tool in that family (workspace, github, http, device, shell). Do not re-read the same skill every step unless needed.
