# DeepEase 1.0.1

Everyday personal assistant on DeepSeek chat — not a developer harness.

## Install
Download **DeepEase-1.0.1.apk** from this release.

## Package
- Application id: `com.endroid.deepease`
- Branch: `deepease`
- Tag: `deepease-v1.0.1`

## Features
- Colorful in-chat theme on chat.deepseek.com
- Everyday tools only: flashlight, Wi‑Fi / Bluetooth / data panels, volume, brightness, timer
- Fenced `invoke` tool calls only
- No shell, workspace, or GitHub agent surface in the product catalog

## Signing
Same release keystore as other Endroid apps when secrets are present.
